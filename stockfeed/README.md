# 공시레이더

미국주식 SEC 공시를 실시간으로 포착해 한국어로 풀어 주고, 공시 뒤 주가가 어떻게 움직였는지 추적하는 웹 서비스입니다.

```
cd stockfeed
npm start            # http://localhost:3000
```

Node 20 이상이면 설치 없이 바로 뜹니다. 기본 기능에는 외부 패키지가 필요 없습니다.

## 기능

| 화면 | 내용 |
|---|---|
| **속보** | 공시 실시간 피드(SSE). 유형별 탭(주요사건·실적·증권발행·지분변동·내부자), 관심종목만 보기, 현재가·전일대비, 포착 후 5·30·60분 주가 반응 |
| **랭킹** | 미국 상장 종목 급등·급락 상위 40. 오늘 공시가 있었던 종목 표시 |
| **리포트** | 오늘 접수 건수, 유형별 분포, 공시 뒤 많이 오른/내린 종목, 주의 공시, 공시가 몰린 종목 |
| **관심종목** | 종목·키워드 등록 → 새 공시가 뜨면 알림함 + 브라우저 알림 |
| **알림함** | 관심종목·키워드에 걸린 공시 최근 100건 |
| **종목 상세** | 시세, 당일 차트, 52주 범위, 최근 공시 40건 |
| 공통 | 달러/원화 전환, 라이트/다크 테마, 종목 검색, 모바일 대응 |

### 한국어 요약은 두 단계입니다

1. **규칙 기반(기본)** — 서식 종류와 8-K 항목 번호를 한국어로 풀어 줍니다. 예: `8-K 3.01` → "상장유지 요건 미달 통지", 주의 표시. 외부 호출과 비용이 없습니다.
2. **AI 요약(선택)** — Claude가 공시 원문을 읽고 2~3문장으로 요약하고 호재·악재·중립을 판단합니다. 아래 환경변수로 켭니다.

## 설정

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 서버 포트 |
| `POLL_MS` | `90000` | 공시 폴링 주기(ms) |
| `SEC_USER_AGENT` | 일반 UA | **운영 시 필수.** SEC는 자동화 클라이언트에 `회사명 연락처이메일` 형식의 User-Agent를 요구합니다. 지정하지 않으면 `www.sec.gov`(전 종목 티커 표, 공시 원문) 요청이 거절될 수 있습니다 |
| `AI_SUMMARY` | 꺼짐 | `1`이면 AI 요약을 켭니다. `npm install`로 SDK를 설치하고 `ANTHROPIC_API_KEY`를 지정해야 합니다 |
| `AI_MODEL` | `claude-opus-5-5` | 요약 모델 |
| `AI_CATEGORIES` | `event,earnings` | AI 요약 대상 유형 |
| `AI_MAX_CHARS` | `60000` | 원문에서 모델에 보내는 최대 글자 수(비용 상한). 넘는 부분은 보내지 않으며, 잘렸다는 사실을 모델에 알립니다 |
| `DATA_FILE` | `data/state.json` | 상태 스냅샷 위치 |

```
SEC_USER_AGENT="MyCompany admin@mycompany.com" AI_SUMMARY=1 ANTHROPIC_API_KEY=sk-... npm start
```

## 데이터 출처

| 데이터 | 출처 | 비고 |
|---|---|---|
| 공시 목록 | SEC EDGAR 전문검색 (`efts.sec.gov`) | 공개 데이터 |
| 종목별 공시 이력, 티커 | `data.sec.gov` | 공개 데이터 |
| 시세·차트 | Yahoo Finance 차트 API | **비공식 API.** 지연될 수 있고 예고 없이 막힐 수 있습니다 |
| 랭킹 | Nasdaq 스크리너 | **비공식 API** |
| 환율 | open.er-api.com | 하루 한 번 갱신되는 값 |

상용 서비스로 운영하려면 시세와 랭킹은 정식 계약된 데이터 공급사(Polygon, IEX, Finnhub 등)로 교체해야 합니다. `server/prices.mjs`의 `quote()`와 `server/market.mjs`의 `ranking()` 두 함수만 바꾸면 됩니다.

## 알아둘 한계

- **포착 시각은 접수 시각이 아닙니다.** 서버가 검색 색인에서 그 공시를 처음 본 시각입니다. 색인 반영과 폴링 주기만큼(보통 1~수 분) 실제 접수보다 늦습니다. 더 빠르게 하려면 EDGAR의 최신 접수 Atom 피드로 바꾸면 되는데, `SEC_USER_AGENT` 지정이 선행되어야 합니다.
- **서버를 켜기 전에 접수된 공시**는 "접수" 날짜만 표시하고 주가 반응을 추적하지 않습니다. 각 서식 묶음을 두 번 훑은 뒤부터 새로 보이는 공시를 실시간 포착으로 인정합니다.
- 장 구간은 요일과 시각만 봅니다. 미국 공휴일 휴장은 반영하지 않습니다.
- 회사명은 영문 그대로입니다(한글 종목명 사전 없음).
- 로그인·결제·커뮤니티는 없습니다. 관심종목과 알림은 브라우저(localStorage)에만 저장됩니다.
- 이 서비스는 정보 제공용이며 투자 권유가 아닙니다.

## 구조

```
server/
  index.mjs      HTTP 서버, API, SSE 방송, 기동
  edgar.mjs      EDGAR 폴링, 티커 조회, 종목 검색
  forms.mjs      서식 분류, 8-K 항목 해석, 한국어 요약 규칙
  prices.mjs     시세, 공시 후 주가 반응 추적
  market.mjs     장 구간, 지수, 환율, 랭킹
  summarize.mjs  AI 요약 (선택)
  store.mjs      메모리 저장소 + JSON 스냅샷
public/          빌드 단계 없는 프런트엔드 (index.html, app.js, style.css)
test/selftest.mjs  네트워크 없이 도는 자체 점검 (`npm test`)
```

### API

| 경로 | 설명 |
|---|---|
| `GET /api/feed?cat=&tickers=&q=&after=&limit=` | 공시 피드. `after`는 마지막으로 받은 공시 id |
| `GET /api/stream` | SSE. `filing`(새 공시), `update`(주가 반응·AI 요약 갱신) |
| `GET /api/market` | 장 구간, 지수, 환율, 오늘 건수 |
| `GET /api/ranking` | 급등·급락 랭킹 |
| `GET /api/today` | 오늘 리포트 |
| `GET /api/stock/:ticker` | 시세 + 최근 공시 |
| `GET /api/search?q=` | 종목 검색 |
| `GET /api/prices?tickers=` | 현재가 일괄 조회(최대 40) |
