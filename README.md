# 어문회 1급 6개월 합격플랜

한국어문회(한국한자능력검정회) **한자능력검정시험 1급**을 6개월(26주)에 준비하는 학습·복습 통합 프로그램입니다.
설치와 서버가 필요 없습니다. `index.html`을 브라우저로 열면 바로 동작합니다.

```
git clone <이 저장소>
cd AiSun
node tools/build.mjs      # 데이터 빌드 (최초 1회, 이미 빌드본이 포함되어 있음)
open index.html           # 또는 파일을 더블클릭
```

학습 기록은 브라우저의 로컬 저장소에 남습니다. 서버로 나가는 데이터는 없습니다.

---

## 무엇을 하는 프로그램인가

시험 대비에서 실제로 어려운 건 "무엇을 볼까"가 아니라 **본 것을 잊지 않는 것**, 그리고 **배점이 큰 곳부터
메우는 것**입니다. 이 프로그램은 그 두 가지를 자동으로 처리합니다.

| 기능 | 설명 |
|---|---|
| **26주 커리큘럼** | 전체 학습량을 3단계 18주에 나눠 배정하고, 마지막 8주는 신규를 끊고 실전만 돌립니다. |
| **기지 급수 건너뛰기** | 보유 급수를 고르면 그 이하는 신규 배정에서 빠집니다. 1급 응시자에게 8급부터 다시 배정하지 않습니다. |
| **간격반복 복습** | 카드마다 다음 복습일을 자동 계산합니다. 잊을 때가 된 것만 그날 꺼내 줍니다. |
| **읽기/쓰기 분리** | 읽을 줄 아는 것과 쓸 줄 아는 것은 별개의 인출입니다. 쓰기 카드는 간격을 20% 짧게 잡습니다. |
| **11개 출제 유형** | 독음·훈음·한자쓰기·완성형·반의어·뜻풀이·동음이의어·부수·유의어·장단음·약자를 모두 문항으로 생성합니다. |
| **실전 모의고사** | 200문항 / 90분 / 160점 합격 — 유형 순서와 배점을 그대로 재현합니다. |
| **오답노트** | 틀린 카드가 자동으로 쌓이고 두 번 연속 맞히면 스스로 빠집니다. 8회 이상 실패하면 **고질 카드**로 표시합니다. |
| **합격 예측** | 유형별 최근 정답률 × 실제 배점으로 예상 점수를 200점 만점으로 환산합니다. |

## 6개월 설계

| 단계 | 기간 | 목표 |
|---|---|---|
| **1단계 기반 다지기** | 1~8주 | 쓰기 배정한자를 읽기·쓰기 동시에 고정. 배점 1위인 한자쓰기(40문항)의 토대. |
| **2단계 1급 확장** | 9~18주 | 1·2급 신출 한자와 성어를 전량 1회전. 신규 유입이 가장 많은 구간. |
| **3단계 실전 완성** | 19~26주 | 신규 중단. 전 범위 회전 + 주 2회 200문항 모의고사로 90분 체력과 점수를 굳힘. |

**하루 루틴 (평일 약 110분)**

1. 예약 복습 25분 — 잊기 직전에 인출해야 오래 간다. 신규보다 **먼저** 끝낸다.
2. 신규 학습 35분 — 머리가 맑을 때. 뜻·부수·대표 어휘를 묶어서 본다.
3. 쓰기 훈련 20분 — 눈으로만 보면 쓰기는 절대 늘지 않는다. 반드시 손으로 쓴다.
4. 유형 드릴 20분 — 요일마다 초점을 돌려 한 주에 11개 유형을 빠짐없이 훈련한다.
5. 취침 전 오답 10분 — 수면 직전 인출은 정착률이 높다.

토요일은 종합테스트(100문항)와 오답 정리, 4주마다 실전 모의고사(200문항). 일요일은 취약 유형 보강과 휴식입니다.

## 수록 데이터

**한국어문회 배정한자 3,500자 전량**을 담았습니다. 급수·훈음·부수·획수는 공개된 공식 자료를 따랐습니다.

| 항목 | 수량 |
|---|--:|
| 배정한자 (8급~1급) | **3,500자** |
| 쓰기 확정 대상 (3급까지 누계) | 1,817자 |
| 쓰기 확장 대상 (2급) | 538자 |
| 통용 훈음이 함께 수록된 한자 | 2,559자 |
| 사자성어·고사성어 | 223개 |
| 유의어·반의어 쌍 | 95쌍 |
| 동음이의어 묶음 | 318묶음 |
| 약자 | 74자 |
| 장단음 어휘 | 79개 |
| **학습 카드 합계** | **6,644장** |

급수별 누계가 3급 1,817자 · 2급 2,355자 · 1급 3,500자로 공식 수치와 정확히 일치하며,
자체 검증이 매번 이를 확인합니다.

### 출처

| 원본 | 제공하는 것 | 라이선스 |
|---|---|---|
| [한국어문회](https://www.hanja.re.kr/) 급수별 배정한자 ([rycont/hanja-grade-dataset](https://github.com/rycont/hanja-grade-dataset) 경유) | 급수·훈음·부수·획수 | **저작권 한국어문회** |
| [libhangul](https://github.com/libhangul/libhangul) 한자사전 | 한자어 어휘·빈도·보조 훈음 | BSD 3-Clause |
| [Unicode Unihan](https://www.unicode.org/Public/UCD/latest/ucd/) | 부수·획수 교차 검증 | Unicode License |

원본 파일은 저장소에 포함하지 않습니다. 재생성 방법과 각 항목의 신뢰도는
[docs/05-원본-데이터.md](docs/05-원본-데이터.md)를 보세요.

**한자어 뜻풀이는 지어내지 않았습니다.** 공개 원본에 없는 항목은 구성 한자의 훈음을 이어 붙입니다
(`家庭 → 집 가 + 뜰 정`). 假定(거짓 가 + 정할 정)과 확실히 구별되고, 한자어를 구성 한자로
분해해 이해하는 건 정석 학습법이기도 합니다.

**아직 얇은 부분**: 유의어·반의어 95쌍(20문항 배점)과 장단음 79개(10문항)는 손으로 정리한
분량이라 상대적으로 얇습니다. `data/src/`의 TSV에 행을 추가하면 바로 반영됩니다.

## 하루에 몇 장인가

배정량은 **이미 아는 급수**에 따라 달라집니다. 설정에서 고르면 그 이하는 신규 배정에서 빠집니다.
(제외된 한자도 드릴·모의고사 범위에는 남으므로, 잊고 있었다면 오답노트를 통해 다시 들어옵니다.)

| 보유 급수 | 신규 배정 | 하루 평균 (주 5일 × 18주) |
|---|--:|--:|
| 제외 없음 | 6,644장 | 74장 |
| 4급까지 *(기본값)* | 4,644장 | 52장 |
| 3급까지 | 3,010장 | 33장 |
| 2급까지 | 1,934장 | 21장 |

여기에 복습이 더해집니다. 1급을 6개월에 끝내는 일이 원래 이만한 분량이라는 뜻이지,
프로그램이 과하게 잡은 게 아닙니다. 감당하기 어렵다면 **보유 급수를 정확히 설정**하거나
시험일을 뒤로 미루는 편이 낫습니다.

## 구조

```
index.html                 진입점 (서버 불필요)
assets/js/core.js          저장소 · 간격반복(SRS) 엔진
assets/js/curriculum.js    카드 덱 · 26주 플랜 · 예상 점수
assets/js/quiz.js          11개 출제 유형 문항 생성기
assets/js/exam.js          모의고사 조립 · 채점 · 약점 분석
assets/js/views.js         화면과 학습 세션 러너
assets/js/app.js           부트스트랩 · 라우터
data/src/*.tsv             편집하는 원본 데이터
assets/data/corpus.js      빌드 산출물 (직접 편집 금지)
tools/import-sources.mjs   공개 원본 3종 병합 → TSV 재생성 (멱등)
tools/build.mjs            TSV → JS 빌드
tools/selftest.mjs         엔진 검증 (58건)
tools/uitest.mjs           실제 브라우저 검증 (33건, playwright 필요)
```

## 개발

```
npm run build     # data/src/*.tsv → assets/data/corpus.js
npm test          # 엔진 검증 58건
npm run uitest    # 브라우저 검증 33건 (playwright 필요)
npm run import    # 공개 원본에서 배정한자 재생성 — docs/05 참조
```

앱 자체는 의존성이 없습니다. Node 18+ 는 데이터 빌드에만, playwright 는 UI 테스트에만 필요합니다.
