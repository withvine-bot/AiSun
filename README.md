# 부수에서 1급까지

한자를 **처음 배우는 사람**이 한국어문회 한자능력검정시험 **1급**까지 올라가는 학습 시스템입니다.
부수 214자부터 시작해 8급 → 7급Ⅱ → … → 1급까지 14칸을 오릅니다.
설치와 서버가 필요 없습니다. `index.html`을 브라우저로 열면 바로 동작합니다.

```
git clone <이 저장소>
cd AiSun
open index.html           # 또는 파일을 더블클릭
```

**파일 하나로 들고 다니려면** `npm run bundle` 을 실행하세요. CSS·스크립트·데이터를 모두
인라인한 `dist/aisun.html` 한 개가 나옵니다. USB에 넣든 메일에 첨부하든 어디서든 돌아갑니다.

학습 기록은 브라우저의 로컬 저장소에만 남습니다. 서버로 나가는 데이터는 없습니다.
그만큼 기기를 바꾸거나 브라우저 데이터를 지우면 사라지므로, **설정 → 백업**에서 주기적으로
내보내 두세요.

---

## 먼저 정직하게

**부수도 모르는 상태에서 1급까지는 6개월로 안 됩니다.** 읽기 3,500자에 쓰기 2,005자,
합격선 80%인 시험입니다. 하루 20장씩 꾸준히 해도 **약 20개월**이 걸립니다.

그래서 이 프로그램은 기간을 먼저 정하지 않습니다. **단계를 정하고, 속도는 학습자가 정합니다.**
남은 기간은 그 속도로 계산해 보여 줍니다. 지키지 못할 계획보다 지킬 수 있는 계획이 낫습니다.

| 하루 새 카드 | 부수 → 1급 예상 | 현실성 |
|---|--:|---|
| 10장 | 약 34.5개월 | 여유롭게. 오래 걸려도 안 무너집니다 |
| **20장** | **약 19.8개월** | 직장인·학생이 지킬 수 있는 속도 |
| 30장 | 약 15.2개월 | 하루 1시간 30분은 필요합니다 |
| 40장 | 약 12.4개월 | 전업 수험생 수준 |

이미 급수가 있다면 그만큼 줄어듭니다 — 3급 보유자가 1급을 목표로 하면 3칸, 약 5개월입니다.

## 어떻게 데려가는가

### 1. 부수 214자부터

부수를 모르면 한자는 그림 3,500장입니다. 부수를 알면 처음 보는 글자도 뜻을 짐작하고,
사전을 찾고, 비슷한 글자를 구별할 수 있습니다. 그래서 첫 칸이 부수입니다.

각 부수마다 **훈음 · 관용 명칭 · 획수 · 놓이는 자리**(변/방/머리/발/엄/받침/몸)와
**모양이 바뀌는 꼴**을 이름과 함께 익힙니다 — `水 → 氵(삼수변)`, `辵 → 辶(책받침)`,
`艸 → 艹(초두머리)`. 여기에 그 부수를 쓰는 배정한자 용례가 급수 표시와 함께 붙습니다.

### 2. 단계마다 관문

각 칸은 두 가지를 다 채워야 열립니다.

1. 배정 카드를 **90% 이상 학습**
2. 그 급수 시험을 **합격선 이상으로 2회 통과** (부수 단계는 1회)

한 번의 요행으로는 넘어가지 않습니다. 관문을 채우면 다음 칸이 자동으로 열리고,
배정과 시험이 그 급수 기준으로 바뀝니다.

### 3. 출제 범위가 단계를 따라간다

> **8급 시험에는 8급 한자만 나옵니다.**

문항 지문에 쓰이는 한자어까지 범위를 지킵니다. 8급 학습자에게 `人間`의 독음을 물으면서
`間`을 보여 주면 시험이 아니라 함정이기 때문입니다. 자체 검증이 매번 이걸 확인합니다.

### 4. 잊는 것을 전제로 설계

카드마다 다음 복습일을 자동 계산합니다(SM-2 변형). 잊을 때가 된 것만 그날 꺼내 줍니다.
읽기와 쓰기는 별개의 인출이므로 **따로 스케줄하고, 쓰기는 간격을 20% 짧게** 잡습니다.
틀린 카드는 오답노트에 자동으로 쌓이고 두 번 연속 맞히면 스스로 빠집니다.
8회 이상 실패하면 **고질 카드**로 표시합니다 — 방법을 바꾸라는 신호입니다.

## 수록 데이터

| 항목 | 수량 |
|---|--:|
| **강희부수** | **214자** (관용 명칭·변형 이름·놓이는 자리·용례 포함) |
| **배정한자 (8급~1급)** | **3,500자** |
| 급수 규격 | 13개 급수 |
| 사자성어·고사성어 | 223개 |
| 유의어·반의어 쌍 | 95쌍 |
| 동음이의어 묶음 | 317묶음 |
| 약자 | 74자 |
| 장단음 어휘 | 79개 |
| **학습 카드 합계** | **6,507장** (읽기 3,500 + 쓰기 2,005 + 부수 214 + 그 밖) |

급수별 누계가 3급 1,817자 · 2급 2,355자 · 1급 3,500자로 공식 수치와 정확히 일치하며,
자체 검증이 매번 이를 확인합니다.

### 출처

| 원본 | 제공하는 것 | 라이선스 |
|---|---|---|
| [한국어문회](https://www.hanja.re.kr/) 급수별 배정한자 ([rycont/hanja-grade-dataset](https://github.com/rycont/hanja-grade-dataset) 경유) | 급수·훈음·부수·획수 | **저작권 한국어문회** |
| [libhangul](https://github.com/libhangul/libhangul) 한자사전 | 한자어 어휘·빈도·보조 훈음 | BSD 3-Clause |
| [Unicode Unihan](https://www.unicode.org/Public/UCD/latest/ucd/) | 부수·획수 교차 검증 | Unicode License |

원본 파일은 저장소에 포함하지 않습니다. 재생성 방법과 항목별 신뢰도는
[docs/05-원본-데이터.md](docs/05-원본-데이터.md)를 보세요.

**한자어 뜻풀이는 지어내지 않았습니다.** 공개 원본에 없는 항목은 구성 한자의 훈음을
이어 붙입니다(`家庭 → 집 가 + 뜰 정`). `假定`(거짓 가 + 정할 정)과 확실히 구별되고,
한자어를 구성 한자로 분해해 이해하는 건 정석 학습법이기도 합니다.

**아직 얇은 부분**: 유의어·반의어 95쌍과 장단음 79개는 손으로 정리한 분량이라 상대적으로
얇습니다. 하위 급수 시험에서는 이 유형의 재료가 모자라 기본 유형으로 대체되며, 대체한
내용은 결과 화면에 표시됩니다. `data/src/`의 TSV에 행을 추가하면 바로 반영됩니다.

## 구조

```
index.html                 진입점 (서버 불필요)
assets/js/core.js          저장소 · 간격반복(SRS) 엔진
assets/js/curriculum.js    급수 사다리 · 관문 · 기간 추정
assets/js/quiz.js          문항 생성기 (부수 유형 포함)
assets/js/exam.js          급수별 모의고사 조립 · 채점
assets/js/views.js         화면과 학습 세션 러너
assets/js/app.js           부트스트랩 · 라우터
data/src/levels.tsv        급수별 시험 규격 — 이 파일이 모든 급수의 기준
data/src/radicals.tsv      강희부수 214자
data/src/*.tsv             한자·성어·유의반의어·동음이의어·약자·장단음
assets/data/corpus.js      빌드 산출물 (직접 편집 금지)
tools/import-sources.mjs   공개 원본 3종 병합 → TSV 재생성 (멱등)
tools/build.mjs            TSV → JS 빌드
tools/bundle.mjs           단일 HTML 파일로 번들
tools/selftest.mjs         엔진 검증 (85건)
tools/uitest.mjs           실제 브라우저 검증 (41건, playwright 필요)
```

## 개발

```
npm run build     # data/src/*.tsv → assets/data/corpus.js
npm test          # 엔진 검증 85건
npm run uitest    # 브라우저 검증 41건 (playwright 필요)
npm run bundle    # 단일 파일 dist/aisun.html 생성
npm run import    # 공개 원본에서 배정한자 재생성 — docs/05 참조
```

앱 자체는 의존성이 없습니다. Node 18+ 는 데이터 빌드에만, playwright 는 UI 테스트에만 필요합니다.
