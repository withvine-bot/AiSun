# 어문회 1급 6개월 합격플랜

한국어문회(한국한자능력검정회) **한자능력검정시험 1급**을 6개월(26주)에 준비하는 학습·복습 통합 프로그램입니다.
설치와 서버가 필요 없습니다. `index.html`을 브라우저로 열면 바로 동작합니다.

```
git clone <이 저장소>
cd AiSun
node tools/build.mjs      # 데이터 빌드 (최초 1회, 이미 빌드본이 포함되어 있음)
open index.html           # 또는 파일을 더블클릭
```

학습 기록은 브라우저의 로컬 저장소에 남습니다. 서버로 나가는 데이터는 없습니다.

---

## 무엇을 하는 프로그램인가

시험 대비에서 실제로 어려운 건 "무엇을 볼까"가 아니라 **본 것을 잊지 않는 것**, 그리고 **배점이 큰 곳부터
메우는 것**입니다. 이 프로그램은 그 두 가지를 자동으로 처리합니다.

| 기능 | 설명 |
|---|---|
| **26주 커리큘럼** | 전체 학습량을 3단계 18주에 나눠 배정하고, 마지막 8주는 신규를 끊고 실전만 돌립니다. |
| **간격반복 복습** | 카드마다 다음 복습일을 자동 계산합니다. 잊을 때가 된 것만 그날 꺼내 줍니다. |
| **읽기/쓰기 분리** | 읽을 줄 아는 것과 쓸 줄 아는 것은 별개의 인출입니다. 쓰기 카드는 간격을 20% 짧게 잡습니다. |
| **11개 출제 유형** | 독음·훈음·한자쓰기·완성형·반의어·뜻풀이·동음이의어·부수·유의어·장단음·약자를 모두 문항으로 생성합니다. |
| **실전 모의고사** | 200문항 / 90분 / 160점 합격 — 유형 순서와 배점을 그대로 재현합니다. |
| **오답노트** | 틀린 카드가 자동으로 쌓이고 두 번 연속 맞히면 스스로 빠집니다. 8회 이상 실패하면 **고질 카드**로 표시합니다. |
| **합격 예측** | 유형별 최근 정답률 × 실제 배점으로 예상 점수를 200점 만점으로 환산합니다. |

## 6개월 설계

| 단계 | 기간 | 목표 |
|---|---|---|
| **1단계 기반 다지기** | 1~8주 | 쓰기 배정한자를 읽기·쓰기 동시에 고정. 배점 1위인 한자쓰기(40문항)의 토대. |
| **2단계 1급 확장** | 9~18주 | 1·2급 신출 한자와 성어를 전량 1회전. 신규 유입이 가장 많은 구간. |
| **3단계 실전 완성** | 19~26주 | 신규 중단. 전 범위 회전 + 주 2회 200문항 모의고사로 90분 체력과 점수를 굳힘. |

**하루 루틴 (평일 약 110분)**

1. 예약 복습 25분 — 잊기 직전에 인출해야 오래 간다. 신규보다 **먼저** 끝낸다.
2. 신규 학습 35분 — 머리가 맑을 때. 뜻·부수·대표 어휘를 묶어서 본다.
3. 쓰기 훈련 20분 — 눈으로만 보면 쓰기는 절대 늘지 않는다. 반드시 손으로 쓴다.
4. 유형 드릴 20분 — 요일마다 초점을 돌려 한 주에 11개 유형을 빠짐없이 훈련한다.
5. 취침 전 오답 10분 — 수면 직전 인출은 정착률이 높다.

토요일은 종합테스트(100문항)와 오답 정리, 4주마다 실전 모의고사(200문항). 일요일은 취약 유형 보강과 휴식입니다.

## 구조

```
index.html                 진입점 (서버 불필요)
assets/js/core.js          저장소 · 간격반복(SRS) 엔진
assets/js/curriculum.js    카드 덱 · 26주 플랜 · 예상 점수
assets/js/quiz.js          11개 출제 유형 문항 생성기
assets/js/exam.js          모의고사 조립 · 채점 · 약점 분석
assets/js/views.js         화면과 학습 세션 러너
assets/js/app.js           부트스트랩 · 라우터
data/src/*.tsv             편집하는 원본 데이터
assets/data/corpus.js      빌드 산출물 (직접 편집 금지)
tools/build.mjs            TSV → JS 빌드
tools/selftest.mjs         엔진 검증 (42건)
```

## 개발

```
node tools/build.mjs      # 데이터 재빌드
node tools/selftest.mjs   # 엔진 자체 검증
```

의존성 없음 · 빌드 도구 없음 · Node 18+ 는 데이터 빌드에만 필요합니다.
