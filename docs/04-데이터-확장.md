# 데이터 스키마와 확장

한자 3,500자는 공개 원본에서 자동 생성됩니다([05-원본-데이터.md](05-원본-데이터.md)).
이 문서는 **직접 손대는 파일**의 형식을 설명합니다 — 성어·유의어·반의어·약자·장단음,
그리고 자동 생성물에 덧씌우는 보강 데이터입니다.

## 흐름

```
공개 원본 3종 ─┐
               ├→ tools/import-sources.mjs →  hanja.tsv, homonyms.tsv ─┐
curated.tsv  ──┘        (멱등, 자동 생성)                              │
                                                                       ├→ build.mjs → corpus.js
idioms.tsv / pairs.tsv / abbrev.tsv / tone.tsv ────────────────────────┘   (직접 편집 금지)
                    (직접 편집)
```

| 파일 | 편집 | 설명 |
|---|---|---|
| `curated.tsv` | **직접** | 자동 생성물에 덧씌우는 보강 데이터 — 진짜 뜻풀이가 달린 어휘, 장단음, 약자, 함께 인정할 훈 |
| `curated-homonyms.tsv` | **직접** | 뜻풀이를 손으로 쓴 동음이의어 묶음 |
| `levels.tsv` | **직접** | 급수별 시험 규격 — 문항 수·합격률·시간·유형별 배분 |
| `radicals.tsv` | **직접** | 강희부수 214자 |
| `idioms.tsv` `pairs.tsv` `abbrev.tsv` `tone.tsv` | **직접** | 성어·유의반의어·약자·장단음 |
| `hanja.tsv` `homonyms.tsv` | 자동 | 임포터가 덮어씁니다. 여기 손으로 쓴 내용은 다음 실행 때 사라집니다. |

빌드하면 수록 건수와 경고(중복 한자, 훈음 누락, 성어/독음 글자 수 불일치)가 출력됩니다.
`assets/data/corpus.js`는 자동 생성물이므로 손대지 마세요.

추가한 뒤 주차별 배정량은 **자동으로 재계산**됩니다. 카드 총량을 18주에 균등 배분하므로
3,500자를 다 넣으면 주당 배정이 그만큼 늘어납니다.

## 파일별 형식

모든 파일은 **탭(TAB) 구분** TSV입니다. `#`로 시작하는 줄은 주석이고, 첫 유효 행은 헤더로 무시됩니다.

### `levels.tsv` — 급수별 시험 규격 (직접 편집)

**이 파일 하나가 모든 급수의 학습 범위·모의고사 구성·합격 판정을 결정합니다.**

```
level  label  read  write  items  pass  minutes  types
8      8급    50    0      50     70    50       독음:25;훈음:25
1      1급    3500  2005   200    80    90       독음:50;훈음:32;한자쓰기:40;…
```

| 열 | 설명 |
|---|---|
| `read` / `write` | 읽기·쓰기 배정한자 누계 |
| `items` / `pass` / `minutes` | 총 문항 수 / 합격률(%) / 시험 시간(분) |
| `types` | `유형:문항수` 를 `;`로 이어 붙임. **합계가 `items` 와 같아야 합니다** — 다르면 빌드가 경고합니다 |

시행처 공고와 다르면 여기만 고치세요. 모의고사·드릴·배점표·합격 판정·예상 점수가 모두 따라옵니다.

### `radicals.tsv` — 강희부수 214자 (직접 편집)

```
char  hun  eum  name      strokes  variants  pos  varNames
水    물   수   물수      4        氵;氺     변   삼수변;아래물수
辵    쉬엄쉬엄갈  착  책받침  7    辶        받침  책받침
```

| 열 | 설명 |
|---|---|
| `name` | 우리말 관용 명칭. 시험에는 안 나오지만 배울 때 이 이름으로 부릅니다 |
| `variants` / `varNames` | 자리에 따라 바뀌는 꼴과 **그 꼴의 이름**. 순서가 짝을 이뤄야 합니다 |
| `pos` | 주로 놓이는 자리 — 변·방·머리·발·엄·받침·몸·제부수 |

용례(그 부수를 쓰는 한자)는 배정한자에서 **자동으로 붙습니다.** 가장 낮은 급수부터 4개까지.

### `curated.tsv` — 보강 데이터 (직접 편집)

공식 자료에 없는 것만 담습니다. 임포터가 자동 생성물 위에 덧씌웁니다.

```
char  hun      tone  variant  words
苛    가혹할   단             苛酷|가혹|몹시 모질고 혹독함;苛斂誅求|가렴주구|세금을 가혹하게 거둠
```

| 열 | 설명 |
|---|---|
| `char` | 한자 한 글자 |
| `hun` | 공식 대표훈과 다르게 알고 있는 훈. **정답으로 함께 인정**됩니다 (덮어쓰지 않습니다) |
| `tone` | `장` / `단` |
| `variant` | 약자 |
| `words` | 대표 어휘 `어휘\|독음\|뜻` 을 `;`로 이어 붙임. **진짜 뜻풀이가 달린 것만** 넣으세요 |

`words`에 넣은 어휘는 자동 선정된 어휘보다 **앞자리**를 차지합니다.
뜻풀이 문항은 여기 적힌 진짜 뜻만 씁니다 — 자동 생성된 "집 가 + 뜰 정" 형태는 쓰지 않습니다.

### `hanja.tsv` — 한자 (자동 생성)

직접 편집하지 마세요. 참고용 형식은 다음과 같습니다.

```
char hun eum radical resid strokes level write tone variant words alts
苛   가혹할 가  艸      5     9      1     N    단           苛酷|가혹|…  매울 가;까다로울 가
```

| 열 | 설명 |
|---|---|
| `radical` / `resid` / `strokes` | 부수 / 부수를 뺀 획수 / 총획 |
| `level` | `8` `7II` `7` `6II` `6` `5II` `5` `4II` `4` `3II` `3` `2` `1` |
| `write` | `Y` 쓰기 확정(3급 이상 누계 1,817자) · `2` 쓰기 확장(2급) · `N` 읽기 전용(1급) |
| `alts` | 채점 시 함께 인정할 다른 훈음 |

### `idioms.tsv` — 사자성어

```
idiom       reading    meaning                              level
苛斂誅求    가렴주구   세금을 가혹하게 거두어 백성을 못살게 굶   1
```

완성형·뜻풀이·독음 문항의 재료입니다. 성어와 독음의 글자 수가 다르면 빌드 시 경고합니다.

### `pairs.tsv` — 유의어 / 반의어

```
kind  unit  a      a_read  b      b_read  note
반의   字    乾      건       坤      곤      하늘 ↔ 땅
유의   語    貢獻    공헌     寄與    기여
```

`kind`는 `유의` 또는 `반의`, `unit`은 `字`(한 글자) 또는 `語`(한자어)입니다.
오답 보기는 **같은 `unit`의 다른 쌍**에서만 뽑으므로 단위를 정확히 넣어야 문항 난도가 맞습니다.

### `curated-homonyms.tsv` — 동음이의어 (직접 편집)

```
reading  words
가정      家庭|한 가족이 사는 집;假定|사실이 아닌 것을 임시로 정함;家政|집안 살림을 다스리는 일
```

한 독음에 **최소 2개** 이상의 한자어가 있어야 문항이 됩니다.
여기 적은 묶음은 자동 생성된 묶음보다 앞에 놓이고, 뜻풀이도 손으로 쓴 것이 그대로 쓰입니다.
`homonyms.tsv`는 이 파일 + 빈도 상위 자동 생성분으로 매번 다시 만들어집니다.

### `abbrev.tsv` — 약자

```
full  abbr  hun   eum
國     国     나라   국
```

정자→약자, 약자→정자 두 방향으로 출제됩니다.

### `tone.tsv` — 장단음

```
word    reading  tone  meaning
講堂    강당      장     강연이나 의식을 하는 큰 방
```

`tone`은 `장` 또는 `단`만 유효합니다. 장단음 문항은 "다음 중 첫 음절이 長音인 것"처럼
**같은 장단끼리 모아 4지선다**로 만들어지므로, 장·단 양쪽에 충분한 수가 있어야 합니다.
이 어휘들은 독음·한자쓰기 문항의 재료로도 함께 쓰입니다.

## 어디부터 채우면 좋은가

배점 대비 수록량이 가장 얇은 곳부터입니다.

1. **`pairs.tsv` — 유의어·반의어 (20문항 배점에 95쌍)**. 여기가 가장 급합니다.
2. **`tone.tsv` — 장단음 (10문항에 79개)**. 순수 암기 유형이라 표본이 곧 실력입니다.
3. **`idioms.tsv` — 사자성어 (15문항에 223개)**. 500개면 넉넉합니다.

스프레드시트에서 작업한 뒤 **탭 구분 텍스트**로 내보내면 그대로 붙일 수 있습니다.
추가한 뒤에는 반드시 검증을 돌리세요.

```
node tools/build.mjs      # 변환 + 데이터 경고
node tools/selftest.mjs   # 엔진 85건 검증
```

## 출제 기준이 바뀌면

`assets/js/curriculum.js`의 `TYPES` 배열이 유일한 기준입니다.

```js
const TYPES = [
  { k: '독음', n: 50, desc: '...' },
  ...
];
```

여기만 고치면 모의고사 문항 배분, 드릴 목록, 배점표, 예상 점수 환산이 전부 따라옵니다.
합격선은 같은 파일의 `PASS_SCORE`입니다.
