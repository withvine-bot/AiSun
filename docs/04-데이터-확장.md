# 데이터 스키마와 확장

수록된 씨앗 데이터는 1급 신출 한자와 쓰기 배정 한자를 중심으로 엄선한 것으로,
공식 배정한자 3,500자 전량이 아닙니다. 커리큘럼·문항 생성·복습 알고리즘은 전량을 넣어도
그대로 동작하도록 만들었습니다. 아래 형식대로 행만 추가하면 됩니다.

## 흐름

```
data/src/*.tsv   →   node tools/build.mjs   →   assets/data/corpus.js
   (편집 대상)              (검증 + 변환)            (직접 편집 금지)
```

빌드하면 수록 건수와 경고(중복 한자, 훈음 누락, 성어/독음 글자 수 불일치)가 출력됩니다.
`assets/data/corpus.js`는 자동 생성물이므로 손대지 마세요.

추가한 뒤 주차별 배정량은 **자동으로 재계산**됩니다. 카드 총량을 18주에 균등 배분하므로
3,500자를 다 넣으면 주당 배정이 그만큼 늘어납니다.

## 파일별 형식

모든 파일은 **탭(TAB) 구분** TSV입니다. `#`로 시작하는 줄은 주석이고, 첫 유효 행은 헤더로 무시됩니다.

### `hanja.tsv` — 한자

```
char  hun  eum  radical  strokes  level  write  tone  variant  words
苛    가혹할  가   艸       9        1      N      단             苛酷|가혹|몹시 모질고 혹독함;苛斂誅求|가렴주구|세금을 가혹하게 거둠
```

| 열 | 필수 | 설명 |
|---|---|---|
| `char` | ✔ | 한자 한 글자 |
| `hun` / `eum` | ✔ | 훈(뜻)과 음(소리). 예: `가혹할` / `가` |
| `radical` | | 부수. 비면 부수 문항에서 제외됩니다 |
| `strokes` | | 총획. 비워도 됩니다 |
| `level` | | 급수 문자열 (`1`, `2`, `3`, `3II`, `4`). 학습 순서 정렬에 씁니다 |
| `write` | | `Y`면 쓰기 배정 한자 — **읽기 카드와 쓰기 카드 두 장**이 만들어집니다 |
| `tone` | | `장` / `단` |
| `variant` | | 약자 |
| `words` | | 대표 어휘. `어휘\|독음\|뜻` 을 `;`로 이어 붙입니다 |

`words`는 독음·한자쓰기·뜻풀이 문항의 재료입니다. **비워 두면 그 글자로는 독음과 쓰기 문항이
만들어지지 않습니다.** 쓰기 대상 한자에는 최소 한 개 이상 넣으세요.

### `idioms.tsv` — 사자성어

```
idiom       reading    meaning                              level
苛斂誅求    가렴주구   세금을 가혹하게 거두어 백성을 못살게 굶   1
```

완성형·뜻풀이·독음 문항의 재료입니다. 성어와 독음의 글자 수가 다르면 빌드 시 경고합니다.

### `pairs.tsv` — 유의어 / 반의어

```
kind  unit  a      a_read  b      b_read  note
반의   字    乾      건       坤      곤      하늘 ↔ 땅
유의   語    貢獻    공헌     寄與    기여
```

`kind`는 `유의` 또는 `반의`, `unit`은 `字`(한 글자) 또는 `語`(한자어)입니다.
오답 보기는 **같은 `unit`의 다른 쌍**에서만 뽑으므로 단위를 정확히 넣어야 문항 난도가 맞습니다.

### `homonyms.tsv` — 동음이의어

```
reading  words
가정      家庭|한 가족이 사는 집;假定|사실이 아닌 것을 임시로 정함;家政|집안 살림을 다스리는 일
```

한 독음에 **최소 2개** 이상의 한자어가 있어야 문항이 됩니다. 1개짜리는 빌드에서 걸러집니다.

### `abbrev.tsv` — 약자

```
full  abbr  hun   eum
國     国     나라   국
```

정자→약자, 약자→정자 두 방향으로 출제됩니다.

### `tone.tsv` — 장단음

```
word    reading  tone  meaning
講堂    강당      장     강연이나 의식을 하는 큰 방
```

`tone`은 `장` 또는 `단`만 유효합니다. 장단음 문항은 "다음 중 첫 음절이 長音인 것"처럼
**같은 장단끼리 모아 4지선다**로 만들어지므로, 장·단 양쪽에 충분한 수가 있어야 합니다.
이 어휘들은 독음·한자쓰기 문항의 재료로도 함께 쓰입니다.

## 대량 추가 요령

1. 스프레드시트에서 작업한 뒤 **탭 구분 텍스트**로 내보내면 그대로 붙일 수 있습니다.
2. `char`가 중복되면 뒤에 온 행이 버려지고 빌드 로그에 경고가 남습니다.
3. 한 번에 몰아 넣기보다, **쓰기 배정 한자(`write=Y`)를 먼저** 채우는 게 점수 효율이 높습니다.
   1단계 8주가 그 글자들로 채워지기 때문입니다.
4. 추가 후 반드시 검증을 돌리세요.

```
node tools/build.mjs      # 변환 + 데이터 경고
node tools/selftest.mjs   # 엔진 42건 검증 (문항 생성이 여전히 되는지 확인)
```

## 출제 기준이 바뀌면

`assets/js/curriculum.js`의 `TYPES` 배열이 유일한 기준입니다.

```js
const TYPES = [
  { k: '독음', n: 50, desc: '...' },
  ...
];
```

여기만 고치면 모의고사 문항 배분, 드릴 목록, 배점표, 예상 점수 환산이 전부 따라옵니다.
합격선은 같은 파일의 `PASS_SCORE`입니다.
