# 원본 데이터와 출처

배정한자 3,500자는 **지어낸 것이 아니라 공개된 권위 자료를 병합해 만든 것**입니다.
이 문서는 무엇을 어디서 가져왔고, 어디까지가 검증된 사실이며, 어디부터가 보조 수단인지 밝힙니다.

## 세 갈래 원본

| 원본 | 제공하는 것 | 라이선스·저작권 |
|---|---|---|
| **한국어문회 급수별 배정한자** — [rycont/hanja-grade-dataset](https://github.com/rycont/hanja-grade-dataset) | 급수, 대표 훈음, 부수, 부수 외 획수, 총획 | **데이터 저작권은 사단법인 [한국어문회](https://www.hanja.re.kr/)에 있습니다.** 해당 저장소는 공식 홈페이지 학습자료실의 xls 파일을 CSV로 옮긴 것입니다. |
| **libhangul 한자사전** — [libhangul/libhangul](https://github.com/libhangul/libhangul) `data/hanja/` | 한자어 어휘와 독음, 어휘 빈도, 보조 훈음 | BSD 3-Clause (Choe Hwanjin) |
| **Unicode Unihan Database** — [unicode.org](https://www.unicode.org/Public/UCD/latest/ucd/) | 부수·획수 교차 검증 | Unicode License |

원본 파일은 이 저장소에 포함하지 않습니다. 각 배포처에서 직접 받아 임포터에 경로를 넘기세요.

## 각 항목의 근거

| 항목 | 근거 | 신뢰도 |
|---|---|---|
| 급수 배정 (8급~1급) | 한국어문회 공식 자료 | **확정.** 누계가 3급 1,817자 · 2급 2,355자 · 1급 3,500자로 공식 수치와 정확히 일치하며, 자체 검증에서 이를 확인합니다. |
| 대표 훈음 | 한국어문회 공식 자료 | **확정.** 훈에 붙는 `다[總]` 같은 한자 주석은 떼어 대표 훈으로 쓰고, 주석형도 정답으로 인정합니다. |
| 부수 · 획수 | 한국어문회 공식 자료 | **확정.** Unihan과 대조하면 3,500자 중 99자(2.8%)가 다른데, 이는 강희부수와 한국 관용 표기의 차이입니다. 시험 기준인 한국어문회 값을 씁니다. |
| 통용 훈음 (채점 시 함께 인정) | libhangul + 공식 자료의 복수 훈음 | 보조. 채점을 **더 너그럽게만** 만들 뿐 오답을 정답으로 바꾸지 않습니다. 2,559자에 수록. |
| 대표 어휘 | libhangul 사전에서 빈도 상위로 선정 | 보조. 배정한자만으로 이뤄진 2글자 한자어 93,035개 중 빈도순 상위 3개를 씁니다. |
| 한자어 뜻풀이 | **합성** — 구성 한자의 훈음을 이어 붙임 | 지어내지 않기 위한 선택. `家庭 → 집 가 + 뜰 정`. 假定(거짓 가 + 정할 정)과 확실히 구별되고, 한자어를 구성 한자로 분해하는 정석 학습법이기도 합니다. |
| 사자성어 · 유의어 · 반의어 · 약자 · 장단음 | 손으로 정리 (`data/src/curated*.tsv`) | 공개된 기계 판독 원본을 찾지 못해 직접 작성했습니다. 아래 "얇은 부분" 참조. |

### 왜 어휘 빈도가 중요한가

사전에는 `敎國`·`家國` 처럼 실제로 쓰이지 않는 표제어도 들어 있습니다.
급수만으로 정렬하면 이런 낱말이 8급 한자의 "대표 어휘"로 뽑힙니다.
libhangul의 `freq-hanjaeo.txt` 빈도로 정렬하면 `敎育·敎授·敎師`, `憂慮·憂愁·杞憂`처럼
제대로 뽑힙니다. 빈도 파일이 없으면 임포터가 경고를 냅니다.

## 아직 얇은 부분

전량 확보한 건 한자 3,500자입니다. 나머지는 손으로 정리한 분량이라 상대적으로 얇습니다.

| 유형 | 배점 | 수록 | 평가 |
|---|--:|--:|---|
| 사자성어 | 15문항 | 223개 | 회당 15문항이므로 당장은 충분하지만, 1급 출제 범위를 덮으려면 500개 이상이 좋습니다. |
| 유의어·반의어 | 20문항 | 95쌍 | **가장 얇습니다.** 200쌍 이상으로 늘리는 게 우선순위입니다. |
| 동음이의어 | 10문항 | 318묶음 | 빈도 상위로 자동 생성되어 충분합니다. |
| 약자 | 3문항 | 74자 | 사실상 전량입니다. |
| 장단음 | 10문항 | 79개 | 얇습니다. 200개 이상이면 좋습니다. |

이 다섯 가지는 `data/src/` 아래 TSV에 행을 추가하면 됩니다. 형식은
[04-데이터-확장.md](04-데이터-확장.md)를 보세요.

## 재생성 방법

```bash
# 1) 원본 확보
git clone --depth 1 https://github.com/rycont/hanja-grade-dataset /tmp/grades
git clone --depth 1 https://github.com/libhangul/libhangul /tmp/libhangul
curl -o /tmp/Unihan.zip https://www.unicode.org/Public/UCD/latest/ucd/Unihan.zip
unzip -q /tmp/Unihan.zip -d /tmp/unihan     # 선택 — 부수 교차 검증용

# 2) 병합 → data/src/hanja.tsv, data/src/homonyms.tsv 재생성
node tools/import-sources.mjs \
  --grades /tmp/grades/hanja.csv \
  --dict   /tmp/libhangul/data/hanja/hanja.txt \
  --unihan /tmp/unihan

# 3) 앱 데이터 빌드 + 검증
node tools/build.mjs
node tools/selftest.mjs
```

임포터는 **멱등**합니다. 같은 원본으로 몇 번을 돌려도 결과가 같습니다.
손으로 쓴 보강 데이터는 `data/src/curated.tsv`와 `data/src/curated-homonyms.tsv`에만 있고,
생성물(`hanja.tsv`, `homonyms.tsv`)을 되읽지 않으므로 덮어써도 사라지지 않습니다.

## 사용에 관하여

배정한자 목록·훈음·부수·획수의 저작권은 한국어문회에 있습니다.
이 저장소는 개인 학습 도구로 만든 것이며, 원본 데이터를 그대로 재배포하지 않고
학습용으로 가공해 담았습니다. 상업적 이용이나 재배포를 계획한다면
**한국어문회에 먼저 문의하세요.** 시험의 출제 기준과 일정 역시 시행처 공고가 최종입니다.
