# 26주 합격 플랜

## 설계 원칙

1. **신규는 18주 안에 끝낸다.** 마지막 8주에 새 글자를 넣으면 복습 부채가 시험일까지 안 사라집니다.
2. **쓰기를 먼저 깐다.** 한자쓰기 40문항은 배점 1위이자 인출 난도 최상입니다. 늦게 시작하면 손이 못 따라옵니다.
3. **복습이 신규보다 먼저다.** 매일 예약 복습을 끝내지 않으면 다음 날 두 배가 됩니다. 이건 며칠이면 무너집니다.
4. **일요일은 쉰다.** 6개월은 짧지 않습니다. 완주가 목표지 완벽이 목표가 아닙니다.

## 3단계

### 1단계 — 기반 다지기 (1~8주)

쓰기 배정한자를 **읽기 카드와 쓰기 카드로 동시에** 학습합니다.
한 글자당 두 장이므로 진도는 느려 보이지만, 이 구간이 시험 점수의 40문항을 결정합니다.

- 매일 신규 카드에는 반드시 **손으로 세 번 쓰기**를 붙입니다. 프로그램의 쓰기 문항이
  객관식이 아니라 "종이에 써 본 뒤 정답 확인 → 자기평가"인 이유입니다.
- 이 단계에서 사자성어와 유의·반의어도 매주 조금씩 섞여 들어옵니다. 한 유형만 몰아서 하면
  다른 유형의 감각이 죽습니다.

### 2단계 — 1급 확장 (9~18주)

1·2급 신출 한자를 전량 1회전합니다. 신규 유입이 가장 많고, 가장 많이 포기하는 구간입니다.

- **복습 예보** 그래프를 매일 확인하세요. 막대가 한쪽으로 치솟으면 그날 100장이 넘게 밀립니다.
- 밀렸다면 신규를 줄이고 복습부터 비웁니다. 프로그램이 밀린 신규를 하루 30장까지 자동으로 따라잡아 줍니다.
- 12주차 즈음 첫 200문항 모의고사에서 점수가 100점대 초반이어도 정상입니다. 유형별 정답률만 보세요.

### 3단계 — 실전 완성 (19~26주)

신규를 끊습니다. 전 범위 회전과 실전만 남습니다.

- 주 2회(수·토) 200문항 모의고사 — **90분을 앉아 있는 체력**을 만드는 게 목적입니다.
- 매 모의고사 뒤 "잃은 점수" 순으로 정렬된 약점표에서 위 3개 유형만 드릴합니다.
- 오답노트의 **고질 카드**(8회 이상 실패)는 방법을 바꾸라는 신호입니다. 같은 방식으로 아홉 번째 봐도 안 외워집니다.
  글자를 쪼개 부수로 이야기를 만들거나, 그 글자가 든 어휘를 문장으로 만들어 보세요.

## 주간 리듬

| 요일 | 내용 |
|---|---|
| 월 | 신규 + 복습 + 드릴(독음·훈음) |
| 화 | 신규 + 복습 + 드릴(한자쓰기·약자) |
| 수 | 신규 + 복습 + 드릴(완성형·뜻풀이) *3단계에는 모의고사* |
| 목 | 신규 + 복습 + 드릴(반의어·유의어) |
| 금 | 신규 + 복습 + 드릴(동음이의어·부수·장단음) |
| 토 | 주간 종합테스트 100문항 + 오답 정리 *4주마다 200문항 모의고사* |
| 일 | 취약 유형 자동 선정 드릴 + 휴식 (신규 없음) |

요일별 초점을 이렇게 돌리면 **한 주에 11개 유형이 빠짐없이 한 번씩** 훈련됩니다.
프로그램이 자동으로 오늘의 초점을 정해 주므로 무엇을 할지 고민할 필요가 없습니다.

## 진행 점검 기준

| 시점 | 이 정도면 정상 |
|---|---|
| 4주차 | 쓰기 카드 100장 이상 착수, 첫 종합테스트 응시 |
| 8주차 | 1단계 배정 완료, 예상 점수 100점대 |
| 12주차 | 첫 200문항 모의고사, 유형별 정답률 표 확보 |
| 18주차 | 전 범위 1회전 완료, 예상 점수 140점대 |
| 22주차 | 모의고사 안정적으로 155점 이상 |
| 26주차 | 모의고사 170점 이상, 고질 카드 20장 이하 |

**예상 점수가 160점을 넘겼다고 끝이 아닙니다.** 예상 점수는 최근 40문항 기준이라 회전이 도는
범위에서만 정확합니다. 실제 시험은 안 본 지 오래된 카드에서도 나옵니다. 마지막 4주는
"모의고사 점수"를 기준으로 판단하세요.

## 밀렸을 때

며칠 빠지는 건 정상입니다. 무너지는 건 밀린 뒤의 대응입니다.

1. **신규를 멈추고 복습부터 비웁니다.** 밀린 복습은 이자가 붙지만 안 배운 글자는 이자가 없습니다.
2. 복습이 정상화되면 신규를 재개합니다. 프로그램이 밀린 배정분을 하루 30장까지 자동으로 얹어 줍니다.
3. 2주 이상 통째로 비었다면 **설정에서 시작일을 조정**해 주차를 다시 맞추세요.
   이미 학습한 카드의 복습 일정은 그대로 유지됩니다.
